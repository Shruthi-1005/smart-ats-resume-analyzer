# Smart ATS Resume Analyzer

## Features
- Resume parsing
- Skill extraction
- ATS score generation
- Resume-job matching
- Suggestions for improvement

## Tech Stack
- Python
- FastAPI
- NLP
- JSON

## Run Project
pip install -r requirements.txt
uvicorn main:app --reload
